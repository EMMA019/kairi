  Kairi Desktop — はじめにお読みください
========================================

【これは何？（約束は1行）】
米国株・日本株の「今日どう？」を、検索と終値付きで日本語で答える相棒です。
LLM / 検索は購入者ご自身の API キー（BYOK）。オフライン完結ではありません。

【動作環境】
- Windows 10 / 11（64bit）
- 推奨配布: zip に runtime\python 同梱 → システムへの Python インストール不要
- 開発用 zip（同梱なし）の場合のみ Python 3.11+ が必要
- ディスク空き: 同梱 Python 込みでおおよそ 300MB〜

【起動方法（10分以内を目標）】
1. zip を任意のフォルダに解凍（例: C:\Apps\Kairi）
2. start_kairi.bat をダブルクリック
3. ブラウザが http://127.0.0.1:8000/ で開く
4. 初回ウィザードで DeepSeek API キーを1つ貼って「保存して始める」
5. 「今日の米国市場どう？」と聞いてみる

終了: 黒い窓で Ctrl+C、または窓を閉じる

【API キー】
- 必須（推奨）: DeepSeek（https://platform.deepseek.com/）
- 任意: Brave Search（検索品質向上）
- API 利用料は各サービスへのお支払い（本製品代金とは別）← 大きくご確認ください

【ライセンス】
- 買い切り同梱。シリアル入力は不要
- 再配布・再販売・共有は禁止（EULA.txt）

【データとプライバシー】
- 会話・設定は PC 内（backend\storage など）に保存
- チャット内容は設定した LLM / 検索プロバイダへ送信される
- 作者サーバーへ会話を送る仕組みはない（BYOK）

【できること（本命）】
- 市況のざっくり把握（指数スナップ・日付の整合）
- 個別銘柄の「なにかあった？」を検索＋終値つきで
- 雑談（株検索に化けない）

【あると便利（上級・既定オフ）】
- Workspace（IDE）/ Char / Market Desk の Radar
- 設定 → System →「上級モード」で表示
- 定期レーダー: 環境変数 KAIRI_ENABLE_SCHEDULERS=1（上級者向け）

【できないこと・注意】
- 医療・投資・法律の専門助言の代替にはなりません
- DRM / ライセンスサーバーはありません

【アップデート（重要：データを消さない）】
新しい zip で更新するとき、会話・設定は backend\storage にあります。

推奨手順:
1. いまの Kairi を終了（黒い窓を閉じる / Ctrl+C）
2. いまのフォルダの backend\storage を別名で退避（例: storage_backup）
3. 新しい zip を別フォルダに解凍する（上書きでも可）
4. 退避した storage を新しい側の backend\storage に戻す
   ※ settings.json / conversations.db を含むフォルダごと戻す
5. start_kairi.bat で起動

やってはいけないこと:
- storage ごと新しい zip で上書きして消す
- 「全部入れ替え」で古い storage を捨てる

詳細メモ: scripts\UPGRADE.txt

【バックアップ】
設定 → 言語 タブ →「バックアップをダウンロード」
既定では API キーはマスクされます（含める場合はチェックを ON）。

【困ったとき（サポート範囲）】
サポートは「起動」と「キー設定」までです。
- Python / runtime が見つからない → 同梱 zip か PATH を確認
- 画面が白い → frontend\dist\index.html があるか確認
- モデルが動かない → DeepSeek キーを確認（初回ウィザードで自動検証）
- ポート 8000 が使用中 → 自動で 8001 以降に切り替えます
- ログ: backend\storage\logs\kairi.log
- API 各社の障害・課金は各社へ
