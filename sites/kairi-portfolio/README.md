# kairi-portfolio

Three.js / React Three Fiber **v8** promo shell for [Kairi](https://github.com/EMMA019/kairi).

This continues the interrupted Render Workspace task. The original `output/` files were wiped with the dyno; this tree is in git so it cannot vanish that way.

Copy is taken from the public README (grounding, BYOK, market desk). It does **not** claim to beat ChatGPT or invent traffic numbers.

## Run

```bash
cd sites/kairi-portfolio
npm install
npm run dev
```

## Cloudflare Pages

- Root directory: `sites/kairi-portfolio`
- Build: `npm run build`
- Output: `dist`

Or snapshot any Kairi Workspace to a dedicated repo with **Push to GitHub**, then point Pages at that repo.
